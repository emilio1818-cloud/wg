## 4. Show HN / Product Hunt (Englisch)

**Titel:** *Show HN: Nestly – an offline-first flatshare app with a zero-dependency sync server*

> Nestly is an app for shared flats: split expenses, a fair chore rota, shopping lists per store and
> contracts with notice-period tracking (based on German consumer law, including a cancellation
> letter generator).
>
> Technically it's a PWA with a tiny Preact-compatible runtime and IndexedDB, and a sync server
> built only on node:http and node:sqlite – no npm dependencies at runtime. Devices sync via a
> generic record store with last-write-wins and server-sent events; Web Push is implemented from
> scratch (RFC 8291). No accounts: devices get a random token, the server stores its hash.
>
> Demo without sign-up: [LINK] · Code (MIT): https://github.com/emilio1818-cloud/wg
>
> I'd love feedback on the sync design and on what would make you trust an app like this with your
> flat's money.

**Wann:** Dienstag bis Donnerstag, ca. 15–17 Uhr deutscher Zeit (Vormittag an der US-Ostküste).
