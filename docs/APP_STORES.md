# Shipping Nestly to the app stores

Nestly is a standards-based PWA, so one codebase reaches every store:

| Store | Route | Notes |
| --- | --- | --- |
| **Web / any phone** | Open the URL → "Add to Home Screen" | Works today. Offline, full-screen, app icon, shortcuts. |
| **Google Play** | Trusted Web Activity (Bubblewrap / PWABuilder) or Capacitor | TWA is the lightest: the Play app is a full-screen Chrome view of your deployed URL. |
| **Apple App Store** | Capacitor (WKWebView) | Apple requires app-like value beyond a website – Nestly's offline mode, haptics and (with the plugins below) local notifications qualify. |
| **Microsoft Store** | PWABuilder | Packages the PWA directly. |

## 1. Deploy the web app + sync server

```bash
docker compose up -d          # or: fly deploy  (see fly.toml)
```

Serve it over HTTPS on your domain (e.g. `https://app.nestly.example`). The server hosts
both the app and the sync API on the same origin, so the app finds its server automatically.

## 2. Google Play via Trusted Web Activity

```bash
npm i -g @bubblewrap/cli
bubblewrap init --manifest https://app.nestly.example/manifest.webmanifest
bubblewrap build
```

Upload the generated `.aab` to the Play Console and publish the Digital Asset Links file
Bubblewrap prints at `https://app.nestly.example/.well-known/assetlinks.json`
(put it into `app/public/.well-known/` and rebuild).

## 3. iOS and Android via Capacitor

`capacitor.config.json` is already in the repository. With package installs available:

```bash
npm i @capacitor/core @capacitor/cli @capacitor/ios @capacitor/android \
      @capacitor/haptics @capacitor/local-notifications @capacitor/share
npm run build                         # produces app/dist (webDir)
npx cap add ios && npx cap add android
npx cap sync
npx cap open ios                      # archive & upload with Xcode
npx cap open android                  # build the bundle with Android Studio
```

Inside the native shell the app is loaded from local files, so set the sync server at build
time:

```bash
NESTLY_SERVER_URL=https://app.nestly.example npm run build && npx cap sync
```

Recommended native integrations (small, isolated changes):

* **Haptics:** replace `navigator.vibrate` in `app/src/components/core.tsx → haptic()`
  with `Haptics.impact()` when `Capacitor.isNativePlatform()`.
* **Share sheet:** `shareText()` in `components/overlays.tsx` → `Share.share()`.
* **Reminders:** schedule local notifications for chores due today and contract deadlines
  (`core/src/chores.ts`, `core/src/contracts.ts` already compute the dates).

## Store listing (suggested)

* **Name:** Nestly – WG-App & Putzplan
* **Subtitle:** Kosten teilen, Einkauf, Verträge
* **Category:** Lifestyle (secondary: Finance / Productivity)
* **Privacy label:** no tracking, no data sold; data stored on the user's sync server.
* **Screenshots:** `docs/screenshots/` (generated by the e2e suite with
  `E2E_SCREENSHOTS=docs/screenshots npm run test:e2e`).
